# Telegram Bot Professional v6

Versão v6 com foco em funil mais forte, painel admin premium e importação de produtos com pareamento automático de preview.

## Novidades da v6

- copy do funil mais forte
- painel admin premium
- campo `tagline` nos produtos
- importação de pasta com pareamento automático de preview:
  - `_preview`
  - `-preview`
  - `(preview)`
- edição de produtos via API
- visual melhorado para operação diária

## Instalação

```bash
npm install
cp .env.example .env
npm start
```
